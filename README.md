Site vitrine statique en français, préparé pour GitHub Pages. Le texte affiché reprend la description publique du show Spotify fourni ; le lecteur intégré est le lecteur officiel Spotify, et la couverture est celle retournée par le service oEmbed de Spotify.

Les balises canonical, `og:url` et le sitemap sont volontairement absents tant que l’adresse GitHub Pages définitive n’est pas connue. Une fois le pseudo GitHub et l’adresse du site confirmés, ces informations pourront être ajoutées sans deviner l’URL.
