# Jour zéro — le roman audio

Site vitrine statique en français pour le show Spotify « Jour zéro — le roman audio ».

- **Site public :** https://manusiaiaiiaiaa-a11y.github.io/jour-z-ro/
- **Dépôt :** https://github.com/manusiaiaiiaiaa-a11y/jour-z-ro
- **Show Spotify :** https://open.spotify.com/show/3jM8llNYCG26GlHMyJD6xJ?si=4fbuesg8R8ep2gtgBvPTEw&nd=1&dlsi=e2191fb3da424aa9

Le titre, le nom du créateur, la description, la couverture et le lecteur proviennent de la page Spotify fournie. Le site ne rajoute pas de biographie, de dates, de distinctions ou de liste d’épisodes recopiée.

La page inclut des métadonnées HTML statiques, une URL canonique, des métadonnées Open Graph et Twitter, des données structurées `PodcastSeries` reliant le show à Spotify, ainsi que `robots.txt` et `sitemap.xml`. Ces éléments aident les moteurs à comprendre et explorer le site, sans garantir son indexation ni la création d’un Knowledge Panel, qui restent décidées par Google.
